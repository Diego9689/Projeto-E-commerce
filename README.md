## 	E-commerce CompFast
## lado da loja
Aplicação da loja
- Usando Supabase
- Cruds
	- Cadastro de categorias de Produtos,
	- Cadastro de Produtos com fotos (fotos salvas no DB)
	- Cupons de Desconto
	- Promoções (com data de expiração, por produto ou categoria)
- Gestão de:
		- Vendas
		- Clientes


## O que não precisa de ter na aplicação do lado da loja

- Logistica; Código, Rastreio, Transportadora, etc
- Nota fiscal

## Lado cliente
SPA/PWA empacotado

- Estilo mercado livre
- Lista de produtos, com destaque para as promoções
- Carrinho de compras
- Cadastro de Clientes no primeiro checkout,
- Persisências: Api do supabase e localstorage

## Identidade Visual
- Estilo e cores semelhantes do Mercado Livre
